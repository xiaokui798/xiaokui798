# 方块世界

一个用原生 JavaScript 和 WebGL 2 制作的单人生存沙盒。你可以探索、挖掘和搭建，也可以用石剑或石斧抵挡一波波僵尸。

地图为 64×24×64。原来 X、Z 从 0 到 31 的区域和建筑位置保留，新地形覆盖 X、Z 从 -16 到 47 的范围。

## 运行

使用 Node.js LTS 和支持 WebGL 2 的桌面浏览器。在 PowerShell 中运行以下命令，无需安装 npm 依赖。

```powershell
Set-Location 'D:\project\world'
node server.js
```

然后在浏览器里打开 `http://127.0.0.1:4173`，从主菜单选择模式。按 `Ctrl+C` 可停止服务。

## 熔炉遗迹

点击「挑战熔炉守卫」进入独立竞技场，守卫入场就会迈步逼近，两次攻击之间会追击或侧移。`6` 和 `7` 分别装备场内提供的石剑和石斧。震地波快到脚下时起跳，扇形横扫和炉火坠落可以跑出地面警戒区。守卫出招后核心会暂时亮成青色，此时近身攻击可以扣血。守卫共有三管血，每波首次出招都会召唤随从。第一波蓄力时可以绕背攻击炉门。第二波会拉开距离，按玩家跑动方向预判火圈，击倒随从可以中断施法。第三波交替冲锋和释放双环星震，横向闪过冲锋可获得三秒反击时间。每打破一管血，本波随从消散，转波时最多恢复 30 点生命。

胜负结算会显示用时和命中数，可立即再挑战。沙盒的建筑、材料和制作进度使用独立的存档。竞技场方块与守卫招式定义在 `boss.mjs`。

## 断星天井

从主菜单选择「挑战断星巨像」。进场后巨像会主动逼近，短暂预警后使出第一招。看到锁定圆圈就离开落点，看到直线光带就向侧面闪避。天井四角的紫青方尖碑是掩体：它们会挡住星脉枪的射线，也会截断三轨折光；绕到侧面后再瞄准巨像。反击窗口结束后，巨像会升空换位，距离过远时会改为追击；贴得太近则会使用低伤害的「星压逼退」把玩家推出近身范围。半血后加入「双环星震」和「三轨折光」。两道震圈靠近时分别起跳。三轨折光可以躲进光带之间，也可以在蓄力时打碎巨像面前的金色晶体，让它提前降下并延长核心暴露时间。

挑战自带星脉枪。按 `8` 装备，左键单发消耗 1 格能量。按住右键约 0.6 秒，看到「松开右键发射」后松开，爆发消耗 2 格、射得更远，可一发打碎金色晶体。按 `R` 补充能量，或在能量用完后再按左键，约 1.2 秒后充满。瞄准暴露的青色核心可以削减巨像生命。

胸口护甲会在反击窗口张开。巨像的护甲和弱点按当前动作的立体模型判定命中。星脉枪蓄力时导轨外张，开火时枪身后坐，补能时能量匣由左手拉出并推回。

## 信标防守

清完五波敌人，同时保护信标。信标失守、玩家倒下或该波超时都会结束挑战。先搭防线或做装备，准备好可以按 `B` 提前开战。待在信标三米左右且无墙阻挡时，按 `E` 消耗 3 个石头，可修复最多 30 点。

游荡者通常追人，突袭者会趁你离开时冲信标，破城者优先打信标。抬手表示即将攻击，普通敌人的蓄力能被近战打断，破城者会继续蓄力。防守结束会显示战果，建筑和背包保留。

## 操作

- `W A S D`：移动；`空格`：跳跃；`Shift`：冲刺
- 旋转跳可先跑起来，起跳后松开 `W`，按 `A` 或 `D` 并向同侧平滑转鼠标。地面上按反方向键可以更快刹停
- 速度表以格/秒显示实时水平速度、本次起跳和空中峰值，以及落地时和 0.20 秒后的速度
- 移动鼠标或使用方向键环视；单击左键破坏准星指向的方块，右键放置
- 鼠标太快时，按 `Esc` 调整鼠标灵敏度。默认 40%，设置会保留在当前浏览器
- `1` 到 `5`：选择方块；`6`：石剑；`7`：制作后装备石斧。滚轮也能切换
- 手持画面与物品栏同步。生存模式的当前方块用完时显示空手
- 准星对准近处的僵尸，单击左键攻击。选中方块也能徒手打。石剑更快、够得更远，石斧单次伤害更高
- 准星变成橙色表示够得着，短暂变成叉形表示命中。物品栏上方的收招条填满后可以再次攻击
- `C`：打开背包与制作，波次会暂停。从游戏内打开背包后，再按 `C` 可直接继续。石斧需要 3 个石头、2 个木头，2 片树叶可以制作一件敷料
- `H`：受伤时使用一件敷料，最多恢复 30 点生命
- `T`：立刻切换晴朗、薄雾和降雨。天气也会随游玩时间变化，走到屋檐下可以避雨
- `M`：静音或恢复音效。开始菜单也可切换，浏览器会记住所选状态
- `Esc`：暂停并释放鼠标。暂停菜单可继续、切换音效，或返回主菜单换模式。返回会结束当前波次，已保存的建筑会保留

浏览器禁止锁定鼠标时，会自动切换为按住左键拖动环视。切换到其他标签页或窗口时，当前一局会暂停。建筑、材料、已制作的石斧和敷料会用当前浏览器自动保存。刷新时会保留这些记录，波次和生命从头开始。旧版建筑会自动读入。另一标签页更新存档后，旧标签页会暂停并提供「载入最新存档」。

进入世界或重新开启音效时会播放一声提示音。移动、起跳、落地、挖掘、放置和攻击也有音效，由浏览器实时合成。

生存模式从 10 个泥土、2 个木头和一把石剑开始。挖掘会获得对应方块，放置会消耗材料。击退僵尸会获得石头和树叶，一波结束后会补充生命。倒下可重生，建筑和背包会保留。自由建造与生存共用地图，拥有不限量的方块，创作时不改变生存背包。

## 维护

`terrain.mjs` 负责地形、坐标和 8×8 区块网格。渲染按距离加载区块网格，挖掘和放置只更新所在区块及受影响的接缝。当前地图是有限边界，体素数据由启动时生成，渲染网格再按距离加载和释放。

`progression.mjs` 负责配方、材料账目和存档版本。新版按坐标存建筑，支持读入前两版存档。`defense.mjs` 管理防守波次、命中判定和信标规则。运行 `node --test` 验证区块、存档、控制、图形恢复和防守规则。要在独立浏览器存档中试验，用 `$env:WORLD_PORT = '4174'` 后启动本地服务。
